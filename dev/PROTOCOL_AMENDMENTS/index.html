    Protocol amendments¶

    The analysis protocol of the benchmark is docs/HYPOTHESES.md together with the code of the analysis (marathonts/hypotheses/). This file records when it was frozen and every change made after the freeze. Changes after the freeze are exploratory: they are not part of the pre-specified analysis.

    Freeze¶

    • Frozen: 21 October 2026, commit 7fea7530b061948199f08777c10045892b1976f8 of the authors' internal repository (the public repository starts from a later, squashed commit). At that commit, HYPOTHESES.md has sha256 4302d5af157afff8776f1ff3c6770714304e7b138ffa3f4473224b264159958b and the analysis code (hypotheses/) has the git tree id 48fb97d374d41467336fd3bdfe26d3db967ef0e2. The commit is available from the authors on request.
    • Main run: carried out on 24 to 26 October 2026, after the freeze. The analysis is pre-specified with respect to the main run.
    • Before the freeze: the replication run (profile min, NVIDIA L4) was completed on 21 October 2026, before the freeze.
