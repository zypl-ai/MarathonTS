    marathonts.bench.methods.register_stitch_suite ¶

    register_stitch_suite(prefix: str, pool: str, overwrite: bool = False, extra_assemblers=(), extra_joiners=()) -> list[str]

    Register the whole stitching suite (config.STITCH_SUITE: the zseries stitcher, the random path, the alternative stitchers of BASELINES.md A–B) on one pool generator: zseries, rand, … — plus custom assemblers () and every seam-processing variant of every stitcher (_; which of them run is Config.smooth_paths / joiners). Every method of the suite shares the pool, so they differ only in the choice, order and seams of the windows. Idempotent; a name already registered with another pool / assembler raises unless overwrite. Returns the method names.
